## 🚀 How to Publish to GitHub Pages (2 Simple Steps)

### Step 1: Create the Repository on GitHub
1. Log in to [GitHub](https://github.com/) with account **asmitayadaw8-star**.
2. Click **New Repository** (`+` icon at top right).
3. Choose one of two repository names:
   - **Recommended:** `asmitayadaw8-star.github.io`  
     *(This makes your public URL: **`https://asmitayadaw8-star.github.io/`**)*
   - **Alternative:** `portfolio`  
     *(This makes your public URL: **`https://asmitayadaw8-star.github.io/portfolio/`**)*
4. Set visibility to **Public** and **DO NOT** initialize with README or .gitignore (we already have them).
5. Click **Create repository**.

### Step 2: Push the Code
In your local terminal inside the `portfolio` folder, run:

```bash
# If you named the repo asmitayadaw8-star.github.io:
git remote add origin https://github.com/asmitayadaw8-star/asmitayadaw8-star.github.io.git
git push -u origin main

# OR if you named the repo portfolio:
git remote add origin https://github.com/asmitayadaw8-star/portfolio.git
git push -u origin main
```

### Step 3: Turn On GitHub Pages
1. Go to your GitHub repository: `https://github.com/asmitayadaw8-star/<repo-name>`.
2. Click **Settings** (top tab) -> **Pages** (left menu).
3. Under **Build and deployment > Source**, select: **GitHub Actions**.
4. That's it! The included `.github/workflows/deploy.yml` workflow will automatically build Vite and deploy the site in under 60 seconds.
